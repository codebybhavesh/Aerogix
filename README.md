# Arogix 🏥

A full-stack healthcare platform designed to improve healthcare accessibility in rural areas by connecting **Patients, Doctors, and Pharmacists** on a single platform.

## ✨ Features

### 👤 Patient
- Secure authentication
- Book medicines in advance
- Video consultation with doctors
- Receive digital prescriptions

### 👨‍⚕️ Doctor
- Manage patient consultations
- Join video calls
- Generate prescriptions

### 💊 Pharmacist
- Manage medicine availability
- Process medicine booking requests

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database & Auth:** Firebase
- **Real-Time Communication:** Socket.io
- **Video Calling:** WebRTC

## 🚀 Getting Started

```bash
git clone <https://github.com/codebybhavesh/Aerogix.git>

npm install

npm run dev
```

## 🎯 Objective

Reduce unnecessary travel for rural patients by enabling online doctor consultations and allowing users to check and reserve medicines before visiting a pharmacy.
